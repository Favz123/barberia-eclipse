# Barbería Eclipse 💈

Landing page demostrativa desarrollada con HTML, CSS y JavaScript.

## Objetivo

Presentar los servicios, precios y datos de contacto de una barbería mediante una página web sencilla, visual y adaptable a dispositivos móviles.

## Funcionalidades

- Presentación de servicios y precios.
- Diseño adaptable a diferentes pantallas.
- Botón de contacto mediante WhatsApp.
- Personalización de información utilizando JavaScript.
- Publicación mediante GitHub Pages.

## Tecnologías

HTML5 · CSS3 · JavaScript

## Demostración

https://favz123.github.io/barberia-eclipse/

## Estado

Proyecto demostrativo para portafolio. No representa a una barbería real ni incluye un sistema automático de reservas.
